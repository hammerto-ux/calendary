# Calendary — ניהול זמן ושתילת אירועים

מיני-סייט (PWA) לניהול לוח שנה ייעודי: רואים את כל הפעילויות במקום אחד,
מונעים התנגשויות (שיבוץ כפול), ומייבאים אירועים אוטומטית מקבצים —
עם אישור אדם לפני כל שתילה.

עובד על אנדרואיד (התקנה למסך הבית) ועל מחשב. אחסון מקומי (offline-first),
ללא שרת חובה.

## הפעלה מקומית
```bash
node server.mjs
```
ואז לפתוח בדפדפן: `http://localhost:5173`

(כל שרת סטטי מתאים — `server.mjs` הוא רק נוחות. חובה לפתוח דרך http/https,
לא דרך file://, בגלל מודולי JS ו-Service Worker.)

## התקנה בטלפון (אנדרואיד)
1. פורסים את התיקייה לאחסון סטטי כלשהו (GitHub Pages / Netlify / כל HTTPS).
2. פותחים את הכתובת ב-Chrome בטלפון.
3. תפריט ⋮ → "התקנת אפליקציה" / "הוספה למסך הבית".
4. לאחר ההתקנה אפשר **לשתף** צילום מסך/PDF ישירות אל Calendary (Web Share Target).

## חילוץ אוטומטי מקבצים
1. מסך **הגדרות** → בוחרים ספק ומזינים מפתח API (נשמר מקומית בלבד):
   - **Gemini** (חינמי): מפתח מ-`aistudio.google.com` (Get API key) — שונה מאפליקציית Gemini.
   - **Claude**: מפתח מ-`console.anthropic.com`.
2. מסך **ייבוא** → גוררים/בוחרים קובץ PDF / DOCX / תמונה.
3. המערכת מחלצת אירועים ומקרא (קודים) ושולחת אותם למסך **אישורים**.
4. במסך אישורים: אשר / ערוך / דחה — שום דבר לא נכנס ללוח ללא אישור.

> ללא מפתח API — כל שאר המערכת עובדת (הזנה ידנית, לוח, צבעים, התנגשויות).
> אפשר גם לנתב דרך Proxy משלכם (שדה בהגדרות) במקום קריאה ישירה מהדפדפן.
>
> **פרטיות:** ב-Gemini Free tier המידע עשוי לשמש את Google לשיפור המוצר. אם הסידור מכיל
> שמות/טלפונים רגישים — עדיף Claude, paid tier, או להסיר פרטים אישיים לפני החילוץ.

## מבנה הקוד
| קובץ | תפקיד |
|------|-------|
| `index.html` / `css/styles.css` | ממשק (RTL, מותאם מובייל, מצב כהה/בהיר) |
| `js/categories.js` | קטגוריות, צבעים, וזיהוי אוטומטי לפי מילות מפתח |
| `js/db.js` | אחסון מקומי (IndexedDB via Dexie) |
| `js/conflicts.js` | מנוע זיהוי התנגשויות |
| `js/parse.js` | נרמול תאריך/שעה, פענוח קודים מהמקרא |
| `js/extract.js` | חילוץ מקבצים באמצעות Claude (ראייה + טקסט) |
| `js/calendar.js` | תצוגת לוח (FullCalendar) |
| `js/app.js` | חיווט מסכים, מודאלים, ייבוא |
| `sw.js` / `manifest.webmanifest` | PWA: offline + Web Share Target |

## חוקי דומיין
- **"חפיפה" = מתלמד שמגיע לצל** — מסווגת `handover`, **אינה** אירוע עצמאי
  ואינה נספרת בזיהוי התנגשויות.
- **התנגשות** = כל חפיפת זמנים אמיתית בין שני אירועים רלוונטיים
  (חג/מועד ו-handover מוחרגים; יום-שלם אינו חוסם משבצות שעה).

## סטטוס
MVP עובד: לוח, הזנה ידנית, מנוע התנגשויות (כולל אזהרה חיה), אחסון, ייבוא+חילוץ,
מקרא, גיבוי/שחזור, PWA.

### הרחבות מתוכננות (שלבים 3–4)
- מעקב תיקיית Google Drive (שתילה אוטומטית מתיקייה ייעודית).
- התראות (חסרים / התנגשויות / קבצים שלא עובדו).
- סנכרון רב-מכשירי.
